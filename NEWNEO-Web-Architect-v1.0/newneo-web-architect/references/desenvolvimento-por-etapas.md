# Protocolo de execução por etapas
Para cada etapa: (1) declarar objetivo, arquivos/áreas afetadas, dependências, critérios de aceite; (2) listar explicitamente áreas protegidas; (3) solicitar autorização; (4) executar mudança mínima; (5) validar build, tipos, lint, fluxos e visual pertinente; (6) relatar testes reais, falhas e riscos; (7) aguardar aprovação; (8) registrar decisão em NEWNEO_PROJECT_STATE.md. Evitar refactors oportunistas. Se houver regressão, corrigir dentro do escopo ou propor plano de recuperação. Não assumir que screenshot aprova performance, SEO ou segurança.
