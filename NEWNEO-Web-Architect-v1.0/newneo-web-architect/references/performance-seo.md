# Performance, SEO e qualidade técnica
Avaliar Core Web Vitals (LCP, CLS, INP) com dados disponíveis, bundle, imagens responsivas, vídeo, lazy loading, fontes, cache e rede. SEO: title/description únicos, canonical, robots, sitemap quando cabível, OG, estrutura de headings, conteúdo indexável e dados estruturados somente com fatos verificáveis. Segurança: segredos, dependências, autenticação/autorização, políticas de banco, links externos e proteção contra abuso conforme arquitetura. Auditoria primeiro sem editar; priorizar por impacto e risco. Não inventar pontuações Lighthouse.
