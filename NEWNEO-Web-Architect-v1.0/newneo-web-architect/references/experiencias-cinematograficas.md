# Motion e experiências cinematográficas — opcionais
Usar somente quando reforçarem narrativa e conversão. Priorizar conteúdo e legibilidade. Para vídeo: poster, preload adequado, autoplay muted playsinline quando aplicável, fallback e compressão; comparar formatos por dispositivo. Para scroll-scrub: medir custo de seeking, testar ida/volta, limpar instâncias GSAP/ScrollTrigger, evitar pinning desnecessário, respeitar reduced motion. Não usar overlays técnicos visíveis ao público sem propósito. Usar gradientes localizados para proteger texto sem escurecer toda a mídia. Testar Safari/iOS físico quando disponível; não afirmar teste físico sem realizá-lo.
